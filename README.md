# MADRL Digital Sandbox: Internet Economy Governance Simulation
# 基于多智能体深度强化学习的互联网经济生态建模与治理

## 📖 项目简介 (Introduction)
本项目是论文《MADRL数字沙盘：基于多智能体深度强化学习的下一代互联网经济生态建模与治理》的官方代码实现。

我们构建了一个基于 **多智能体深度强化学习 (MADRL)** 的仿真环境，模拟了互联网平台、生产者与消费者之间的动态博弈，用于评估不同治理政策（如反垄断、隐私保护、通证经济）对市场结构和生态健康的影响。

## 🛠️ 环境依赖 (Requirements)
本项目基于 Python 3.8+ 开发，依赖以下库：
- PyTorch
- NumPy
- Matplotlib
